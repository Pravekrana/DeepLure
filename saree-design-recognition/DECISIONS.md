# Decisions
- User's deadline is 2 October 2026 at 11:59 AM IST = 06:29 UTC. No submission action authorized.
- Exact motif/layout identity is the target; category/folder names cannot establish identity.
- Keep data and derived artifacts under private/, excluded from explicit shareable allowlist.
- CPU environment: begin with MobileNetV3 Small IMAGENET1K_V1, retain compatible installed torch packages.
- Preserve aspect ratio by fitting within 224 square, neutral padding; checkpoint mean/std normalization. This intentionally replaces checkpoint center crop to retain borders.
- Baselines use normalized pooled 576-D features; trained projection is 256-D, shared by train/inference.
- Synthetic tests provide software evidence only. Missing genuine labels will trigger an explicit instance-contrastive fallback, not fabricated design evaluation.
- Metadata and AI-assisted visual audit do not establish natural design/capture/colorway truth. Exclude vendor repeated-view families rather than count crops as independent queries. Public Kaggle images support explicit instance-contrastive training and controlled synthetic evaluation only.
- Source license discrepancy: Kaggle API says CC0, bundled Roboflow README says MIT. Disclose both; do not redistribute images or trained artifacts in shareable ZIP.
- The initial Windows-mounted virtualenv installation is unusually slow; a temporary local Linux virtualenv is used for execution if needed. No system packages or accelerator installations are replaced. Final exact tested versions will be pinned.
- Software smoke initially used random weights, but with fixed batch-normalization statistics the backbone produced almost constant outputs; the collapse guard correctly rejected it. Use pretrained initialization for the end-to-end smoke too. Random weights remain confined to isolated unit tests, never real baselines.
- Audit summary initially counted policy exclusions as exact duplicates. Corrected aggregate counting before reporting; raw manifest and frozen split were not changed. True exact-pixel duplicates: 5.
- Final source data count: Kaggle 1468, vendor 165. All vendor thumbnails inspected with AI assistance; dimensions often occur in nearly identical groups of five, consistent with related crops/views, insufficient evidence of independent captures.
- Before final test access, validation channel-permutation retrieval saturated (mAP near 1). Add a secondary invertible RGB complement (255-x) stress, in addition to grayscale, with the primary validation-recolor threshold frozen. This probes contrast-polarity changes; it is still a synthetic copy, not a new capture. No training/checkpoint changes are selected using test results.
- Corrected a data-audit implementation deficiency after v1 test: dHash≤4 missed visually near-identical, slightly resampled photographs (one val/test pair). Complement with 32×32 bilinear RGB mean absolute difference≤0.025, conservatively grouping similar captures/render backgrounds. A detected train/test pair depicts upholstery on the same chair, showing the public dataset contains non-saree/background shortcuts. This screening is not an identity label. Rebuild all splits and retrain unchanged configurations. V1 results are superseded; report the repeat and prior dataset exposure explicitly rather than claiming an untouched holdout.
- The no-color ablation changes one configuration flag with the same seed, sampler, architecture, optimizer and budget. Skipping color transforms changes Torch RNG consumption, so individual translation draws are not bit-matched across variants, although their distribution is unchanged. This is a single-seed ablation, not an uncertainty estimate.
