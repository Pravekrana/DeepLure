# Data retention
The vendor corpus belongs to third parties. Do not redistribute it. Delete downloaded project copies when this exercise concludes, including images, crops, thumbnails, contact sheets, embeddings, model checkpoints, temporary files, and image-bearing notebook outputs. The local app binds to localhost and must not be exposed publicly. Do not upload vendor data to Kaggle without specific hosting rights.

`private/` contains project-created working copies only. Raw user originals must never be placed there. No private source identifier, filenames, image examples, embeddings, or weights are included in the shareable archive. Public-source imagery is also excluded because reported licenses differ. Access to trained artifacts for an authorized reviewer should use a private approved channel after rights are confirmed, or regenerate locally from authorized sources.

After the exercise: `python scripts/cleanup.py` previews the exact scope. `python scripts/cleanup.py --exercise-concluded --delete-project-copies` deletes only the marked project `private/` directory, refuses a symlink, and does not follow links to delete external targets. Do not execute deletion while work or live review still needs the assets.

The cleanup script also lists and deletes the six exact temporary acquisition files created by this run (`/tmp/deeplure_sample`, `/tmp/deeplure_retry.jpg`, and four named HTML/JSON metadata files). It does not use a wildcard and refuses to delete a temporary symlink. Other temporary environments contain only software, not corpus images. The project PDF is the user's original and must remain untouched. Standard Python caches and the environment contain no dataset images. The final ZIP is built from a reviewed explicit file allowlist rather than relying on `.gitignore`.
